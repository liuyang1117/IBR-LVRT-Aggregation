# Data / 数据说明

This folder contains parameter summaries and case-to-code mapping tables.

本文件夹保存算例参数汇总表和代码对应关系表。

The numerical data are intended for documentation and reproducibility. The MATLAB scripts are self-contained and do not require reading these CSV files during execution.

这些数据主要用于说明和复现。MATLAB 主程序是自包含的，运行时不依赖这些 CSV 文件。
