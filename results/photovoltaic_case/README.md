# Results / 结果文件夹

This folder is reserved for figures and numerical results generated by the MATLAB scripts.

本文件夹用于保存 MATLAB 程序运行后生成的图像和数值结果。

## What to Put Here / 这里放什么

You can put the following files in this folder:

可以在这里放以下文件：

```text
pcc_current_comparison.png
aggregation_error_decomposition.png
common_voltage_reduction_error.png
admissible_law_approximation_error.png
propagation_operator_norm.png
terminal_voltage_profile.png
case_summary.csv
```

## Suggested Rule / 建议规则

Large result files should not be uploaded unless they are necessary for reproducing the paper figures.

如果结果文件很大，除非论文复现必须使用，否则不建议上传到仓库。

## Recommended Subfolders / 推荐子文件夹

```text
results/
├── photovoltaic_case/
├── wind_farm_case/
└── summary/
```

- `photovoltaic_case/`: figures and data generated by `photovoltaic_case.m`  
  存放光伏算例生成的图像和数据

- `wind_farm_case/`: figures and data generated by `wind_farm_case.m`  
  存放风电场算例生成的图像和数据

- `summary/`: summarized comparison tables  
  存放汇总对比表格
