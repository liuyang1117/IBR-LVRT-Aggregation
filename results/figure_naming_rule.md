# Figure Naming Rule / 图像命名规则

This document gives a recommended naming rule for generated figures.

本文档给出生成图像的推荐命名规则。

## Naming Format / 命名格式

```text
case_name_figure_content.png
```

For example:

例如：

```text
photovoltaic_pcc_current_comparison.png
photovoltaic_error_decomposition.png
wind_farm_pcc_current_comparison.png
wind_farm_error_decomposition.png
```

## Recommended Names / 推荐名称

### Photovoltaic Case / 光伏算例

```text
photovoltaic_pcc_current_comparison.png
photovoltaic_error_decomposition.png
photovoltaic_common_voltage_reduction_error.png
photovoltaic_admissible_law_approximation_error.png
photovoltaic_terminal_voltage_profile.png
```

### Wind Farm Case / 风电场算例

```text
wind_farm_pcc_current_comparison.png
wind_farm_error_decomposition.png
wind_farm_dq_decomposition.png
wind_farm_propagation_operator_norm.png
wind_farm_terminal_voltage_profile.png
```

## Notes / 注意事项

Use clear English file names because they are easier to cite in papers, README files, and GitHub links.

建议使用清晰的英文文件名，因为更方便在论文、README 和 GitHub 链接中引用。
