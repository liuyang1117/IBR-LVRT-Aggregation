# Examples / 运行示例

This folder provides simple examples for running the MATLAB LVRT aggregation cases.

本文件夹提供 MATLAB 低电压穿越聚合等值算例的运行示例。


## Error-Term Terminology / 误差项术语

The examples use the following error-term names:

示例文件统一采用以下误差项名称：

| Symbol | English name | 中文名称 |
|---|---|---|
| `ecv` / `e_cv` | Common-Voltage-Reduction Error | 同电压压缩误差 |
| `eal` / `e_al` | Admissible-Law-Approximation Error | 允许函数类近似误差 |
| `e` / `etot` | Total aggregation error | 总聚合误差 |

## Files / 文件说明

| File | Description | 中文说明 |
|---|---|---|
| `run_example.md` | Basic example for running both cases | 基础运行示例 |
| `photovoltaic_case_example.md` | Example for the six-PV case | 六光伏算例运行说明 |
| `wind_farm_case_example.md` | Example for the offshore wind farm case | 海上风电场算例运行说明 |
| `result_check_example.md` | Example for checking generated results | 结果检查示例 |

## Recommended Order / 推荐顺序

```text
1. photovoltaic_case_example.md
```
